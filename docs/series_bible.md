# IRL BUT CHEATS - series bible

**Premise.** Dave (broke, anxious, impulsive) discovers a developer console floating in front of
his face. Real life accepts cheat codes. Every episode he finds one, uses it badly, and the
consequences escalate. The Admin, a bored moderator who nobody asked for, issues three warnings
per season before pressing the ban button.

**Tone.** Deadpan, low budget, and proud of it. The jank is the joke: T-poses, clipping,
mouths that do not match, loading screens with sarcastic tips.

## Cast
| | |
|---|---|
| **Dave** | Orange hoodie. Four dollars and a bagel coupon. Believes every plan is "fine". |
| **Kyle** | Blue hoodie, deadpan best friend, the only person Dave tells. Low standards, high commentary. |
| **The Admin** | Floating red crystal. Moderates because it was "very quiet". Escalating warnings. Knows a guy called Greg. |
| **NPCs** | Repeat one line forever. "Nice weather today." Occasionally become load-bearing to the plot. |

## Rules of the world
1. Cheats work, but literally, and on whatever is nearest.
2. Every cheat has a bug. Fixing a bug creates a second bug.
3. NPCs never notice anything unless it is on their one line.
4. The Admin has three warnings per season. Each is more polite than the last.
5. Game UI exists in the world (console, toasts, HP, FPS). FPS drops when things get out of hand.

## Running gags
"Nice weather today." / Gerald, who is still waiting for a bus / the Admin pretending to be a plant / the bagel coupon / loading-screen tips / Greg / achievements for terrible things / Dave's HP / the FPS counter / the final line of each episode is Kyle saying "Dave."
